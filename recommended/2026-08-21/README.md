이 코호트는 **다기관·다기기로 수집된 이질적 데이터에서 다중 라벨 소견 분포가 매우 불균형**하다는 특징을 가지므로, 기관 간 일반화 성능과 저빈도 소견에 대한 정밀도가 핵심 관심사다.

## 채택 논문

### 1. Multicenter evaluation of four large language models for automated spine imaging diagnosis
- **저널**: npj Digital Medicine (2026-08-08, OpenAlex)
- **링크**: https://doi.org/10.1038/s41746-026-03133-z
- **관련성**: 3개 기관 20,277건의 척추 영상 리포트를 활용한 다기관 LLM 진단 비교 연구. 전반적으로 높은 특이도(>90%)와 음성예측도(>96%)를 보였지만, 저빈도 질환에서는 정밀도가 19~42%포인트 하락함을 보고. 우리 코호트에서 Pneumothorax(5건), Nodule(7건) 등 저빈도 소견의 신뢰도를 해석할 때 참고할 수 있는 정량적 근거를 제공.
- **한계**: 텍스트 리포트 기반 LLM 진단이며 영상 자체 판독이 아니므로, 우리 데이터의 영상 기반 판독 성능은 확인 불가.

### 2. An explainable generative AI system for video-to-report generation in capsule endoscopy (CE Reporter)
- **저널**: npj Digital Medicine (2026-08-06, OpenAlex)
- **링크**: https://doi.org/10.1038/s41746-026-03079-2
- **관련성**: 다기관·다기기(1002건, MICS-CE 데이터셋) 캡슐내시경 영상을 자동 리포트화하며, 기관·기기 간 F1 0.72~0.81의 안정적 성능과 91.9% 판독 시간 단축을 보고. 우리 코호트도 5개 기관·9종 장비로 구성된 이질적 다기관 데이터로, 자동 판독 시스템이 기관·장비 간 이질성에서 유지 가능한 성능 범위를 가늠하는 참고가 됨.
- **한계**: 캡슐내시경 동영상-리포트 생성 과제로, 정지 영상 기반 흉부 X-ray 다중 라벨 분류와는 과제 성격이 달라 직접적 수치 비교는 제한적.

### 3. QoQ-Med3: a multimodal reasoning foundation model for clinical analysis
- **저널**: npj Digital Medicine (2026-07-25, OpenAlex)
- **링크**: https://doi.org/10.1038/s41746-026-02945-3
- **관련성**: 공개 데이터로만 학습한 다중모달 파운데이션 모델이 학습에 사용되지 않은 타 기관(Johns Hopkins JHU PMAP 등) held-out 데이터셋에 일반화됨을 보이고, 환각률을 44.4% 감소시킴. 우리 코호트처럼 5개 기관에서 수집된 다기관 데이터에 외부 검증 없이 단일 모델을 적용할 때의 위험과 가능성을 함께 시사.
- **한계**: 초음파·유방촬영 등 범용 모달리티 평가로 흉부 X-ray 다중 라벨 분류에 특화된 성능 수치는 별도 보고되지 않음.
